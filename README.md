## 🚀 Getting Started

### Prerequisites
- Basic knowledge of any programming language
- A code editor (VS Code, IntelliJ, etc.)
- Compiler/Interpreter for respective languages:
  - Python: `python3`
  - Java: `javac` and `java`
  - C: `gcc`
  - C++: `g++`

### Installation
```bash
# Clone the repository
git clone <repository-url>
cd AI-Placement-Prep-Portal

# For Python (no installation needed)
python3 python/beginner/01_hello_world.py

# For Java
cd java/beginner
javac HelloWorld.java
java HelloWorld

# For C
cd c/beginner
gcc -o hello_world hello_world.c
./hello_world

# For C++
cd cpp/beginner
g++ -o hello_world hello_world.cpp
./hello_world
```

## 💡 How to Use This Portal

### For Each Problem:
1. **Read the problem** in the source file comments
2. **Understand the requirements** and examples
3. **Try solving independently** first (important!)
4. **Compare with provided solution** only after attempting
5. **Analyze the approach** and complexity
6. **Self-assess** using the assessment criteria

### Best Practices:
- ⭐ Don't peek at solutions immediately
- ⭐ Try harder problems to push your limits
- ⭐ Understand concepts, don't memorize
- ⭐ Write comments in your code
- ⭐ Test edge cases
- ⭐ Track your progress religiously

## ✅ Assessment Framework

Each solution is evaluated on:

### 1. **Correctness** (40%)
   - Does it produce the right output?
   - Edge cases handled?
   - No runtime errors?

### 2. **Code Quality** (30%)
   - Readability
   - Proper naming conventions
   - Well-structured functions
   - Comments where needed

### 3. **Efficiency** (20%)
   - Time Complexity
   - Space Complexity
   - Optimization

### 4. **Best Practices** (10%)
   - Error handling
   - Resource management
   - Language conventions

**Pass Mark:** 70+ out of 100

## 🐛 Troubleshooting

### Problem won't compile/run?
- Check syntax for that language
- Ensure correct compiler is installed
- Look for typos in variable names

### Getting wrong output?
- Check if you understood the problem correctly
- Test with edge cases (empty, single element, etc.)
- Print intermediate values to debug
- Trace through your algorithm manually

### Solution is too slow?
- Check if you're doing unnecessary iterations
- Consider using better data structures
- Look for optimization techniques (sliding window, two pointers, etc.)
