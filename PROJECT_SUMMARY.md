## 🚀 Quick Start (5 Steps)

### Step 1: Navigate to Project
```bash
cd /workspaces/AI-Placement-Prep-Portal
```

### Step 2: Choose Your Language
- Python (recommended for beginners)
- Java
- C
- C++

### Step 3: Open First Problem
```bash
# For Python
cat python/beginner/01_hello_world.py

# For Java
cat java/beginner/HelloWorld.java

# For C
cat c/beginner/hello_world.c

# For C++
cat cpp/beginner/hello_world.cpp
```

### Step 4: Run & Test
```bash
# Python
python3 python/beginner/01_hello_world.py

# Java
cd java/beginner && javac HelloWorld.java && java HelloWorld && cd ../..

# C
gcc -o test c/beginner/hello_world.c && ./test

# C++
g++ -o test cpp/beginner/hello_world.cpp && ./test
```

### Step 5: Track Progress
- Edit `PRACTICE_TRACKER.md`
- Mark completed problems
- Note challenges
- Plan next problems
